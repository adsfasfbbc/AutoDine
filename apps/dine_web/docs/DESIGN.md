# AutoDine 设计系统

## 品牌

产品名 **AutoDine**：无人餐厅与甜品店前端中枢。视觉原则：简约、美观、大气；保留**蓝色与橙色**
作为品牌识别线索，但避免模板化科技蓝与过度装饰。

- 消费者端：温暖、有食欲（暖纸底、食物摄影、甜品气质）
- 生产端：沉稳、可执行（深海军蓝侧边栏）
- 管理端：冷静、数据化（墨色侧边栏）

## 消费者端双模式

- **B 普通电脑页面**：默认入口，保留搜索、热量/过敏原筛选、商品详情、Agent、排队与订单导航。
- **A 门店自助点餐**：由 B 顶栏显式进入 `/consumer/kiosk`，采用独立全屏布局；不会因窗口宽度误切换。
- 两种模式复用同一菜单、购物车和订单状态。B 中的已选商品进入 A 后保留，A 加购后返回 B 也会同步显示。
- A 使用深海军蓝顶栏、饱和分类色块、食物大图与常驻右侧订单栏，优先服务 1440×900 和 1920×1080 横屏触控场景。

## 色彩令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `brand-900` | `#14293d` | 主品牌深海军蓝（导航激活、标题） |
| `brand-500` | `#3b729c` | 主色中阶（链接、焦点） |
| `accent-500` | `#d97a2e` | 暖食橙（价格、CTA、取餐码） |
| `paper` | `#faf7f2` | 纸张暖灰（消费者端背景） |
| `ink-900` | `#17202a` | 正文墨色 |
| `line` | `#e9e3d9` | 暖色描边 |
| `success/danger/warning` | — | 状态语义（售罄、告警、完成） |

语义色保证 WCAG AA 对比度；**状态信息不只依赖颜色**（售罄同时有文字与图标）。

## 字体

- 显示标题：`Noto Serif SC`（思源宋体，600/700），甜品品牌的高级感来源
- 界面正文：系统无衬线栈（PingFang SC / Microsoft YaHei / Segoe UI）

## 版式

- 桌面目标：1440×900 / 1920×1080，内容区最大宽 1440px 居中
- 圆角语言：卡片 `rounded-2xl`，按钮/胶囊 `rounded-full`
- 阴影极轻：`0 1px 2px rgba(20,41,61,0.04)`，悬停提升不超过 12px 投影

## 动效

- **单一主记忆动效**：首页角色入口的「传菜带」式入场（`anim-plate`，从左滑入 + 微旋转，错峰 110ms）
- 页面切换：220ms 淡入 + 6px 上移（`page` 过渡）
- 交互反馈：200ms 标准缓动（`--ease-standard`），按钮按下 `scale(0.98)`
- B → A：支持浏览器 View Transition 时使用原生过渡，并以 450ms 圆形揭幕作为 A 的入场语言；不支持时直接导航。
- A 加购按钮：220ms 短促回弹，只作为点击反馈，不持续播放。
- `prefers-reduced-motion`：全局禁用位移/缩放动画，保留淡入与即时状态反馈

## 组件语言

- `card`：白底 + 暖描边 + 极轻阴影
- `chip`：小胶囊标签（筛选、状态、过敏原）
- `btn-accent` / `btn-ghost`：主/次按钮
- `eyebrow`：小号大写英文眉题（区段引导）

## 可访问性

- 键盘可操作：全部交互元素可聚焦，`focus-visible` 显示 2px 品牌色描边
- 语义化：nav/label/aria-label 覆盖导航与表单
- 动效偏好、对比度、非颜色状态表达均已内置
